## Project Description
A Python 3 console tool that analyses typed text or a text file and reports the number of words, characters, sentences, unique words, and frequency of each word.

## Features
- Reads text typed by the user or from a .txt file.
- Counts words and characters with and without spaces.
- Counts sentences and unique words.
- Case-insensitive counting.
- Removes punctuation before counting words.
- Uses dictionaries for word frequency.
- Uses sets for unique words.
- Sorts results by frequency and alphabetically.
- Handles invalid input and missing files.

## Concepts Used
- Strings
- Dictionaries
- Sets
- Sorting
- File Handling
- Exception Handling

## Requirements
- Python 3.6 or above.
- No external libraries.
